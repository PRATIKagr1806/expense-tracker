# Expense Tracker

**Live demo:** [https://pratik01234.pythonanywhere.com]

A multi-user web app to track daily expenses, built with Flask and SQLite.

## Features
- User registration and login (hashed passwords, sessions)
- Each user sees only their own expenses
- Add and delete expenses
- Spending by category (pie chart)
- Daily and monthly spending (tables and bar charts)

## Tech used
Python, Flask, SQLite, HTML/CSS, Chart.js

## How to run
1. Install Flask: `pip install flask`
2. Run: `python app.py`
3. Open http://127.0.0.1:5000
